Add an optional event details popover. `eventPopover="click" | "hover"` on `Calendar`, `MonthView` and `TimeGridView` shows an event's color, title, date and time, location and description, using the native Popover API. `renderEventPopover` replaces its content, and new `classNames` slots (`eventPopover*`) and an `eventWhen` formatter customize it.
